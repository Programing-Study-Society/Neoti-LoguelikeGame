# 攻撃ボタンパネル設定ガイド

## 概要

攻撃ボタンパネルは、アイテム選択後に表示され、敵の数に応じて動的に攻撃ボタンを生成します。

## Hierarchy構造

```
BattleScreen
└── AttackButtonPanel (GameObject)
    └── AttackButtonContainer (GameObject, HorizontalLayoutGroup)
        └── [動的生成] AttackButton × n
```

## 設定手順

### 1. AttackButtonPanelの作成

1. `BattleScreen`オブジェクトを選択
2. 右クリック → **Create Empty** → 名前を **"AttackButtonPanel"** に変更
3. **RectTransform**の設定:
   - **Anchors**: Middle-Center（中央配置）
   - **Width**: `600`（ボタンが横並びに収まるサイズ）
   - **Height**: `150`
   - **Position**: `(0, -200, 0)`（画面下部中央）

### 2. AttackButtonContainerの作成

1. `AttackButtonPanel`を選択
2. 右クリック → **Create Empty** → 名前を **"AttackButtonContainer"** に変更
3. **RectTransform**の設定:
   - **Anchors**: Stretch-Stretch（親に合わせて拡張）
   - **Left/Right/Top/Bottom**: `10`（余白）
4. **HorizontalLayoutGroup**コンポーネントを追加:
   - **Spacing**: `20`（ボタン間の間隔）
   - **Child Alignment**: Middle Center（中央揃え）
   - **Child Force Expand**: 
     - **Width**: チェック（ボタンが均等に拡張）
     - **Height**: チェック
   - **Child Control Size**:
     - **Width**: チェック（ボタンの幅を制御）
     - **Height**: チェック（ボタンの高さを制御）

### 3. AttackButtonプレハブの作成

1. `AttackButtonContainer`を選択
2. 右クリック → **UI → Button - TextMeshPro** → 名前を **"AttackButton"** に変更
3. **RectTransform**の設定:
   - **Width**: `200`
   - **Height**: `60`
4. **Button**コンポーネントの設定:
   - **Interactable**: チェック
   - **Transition**: Color Tint（デフォルト）
5. **TextMeshProUGUI**（子オブジェクト）の設定:
   - **Text**: "攻撃する"（プレハブ作成時のデフォルト、実行時に変更される）
   - **Font Size**: `24`
   - **Alignment**: Center（中央揃え）
6. **プレハブ化**:
   - Projectウィンドウで `Assets/Prefabs/UI/` フォルダを確認
   - Hierarchyの`AttackButton`をProjectの `Assets/Prefabs/UI/` にドラッグ&ドロップ
   - Hierarchyから元の`AttackButton`を削除

### 4. BattleScreenコンポーネントの設定

1. `BattleScreen`オブジェクトを選択
2. Inspectorで`BattleScreen`コンポーネントを確認
3. **攻撃ボタン**セクションで以下を設定:
   - **Attack Button Panel**: `AttackButtonPanel`オブジェクトをドラッグ&ドロップ
   - **Attack Button Container**: `AttackButtonContainer`オブジェクトをドラッグ&ドロップ
   - **Attack Button Prefab**: `Prefabs/UI/AttackButton.prefab`をドラッグ&ドロップ

## 動作仕様

### ボタンの生成ルール

- **敵が1体の場合**:
  - 「攻撃する」ボタン1つ

- **敵が2体の場合**:
  - 「左の敵に攻撃」ボタン
  - 「右の敵に攻撃」ボタン

- **敵が3体以上の場合**:
  - 「左の敵に攻撃」ボタン（最初の敵）
  - 「敵2に攻撃」ボタン（中間の敵）
  - 「敵3に攻撃」ボタン（中間の敵）
  - ...
  - 「右の敵に攻撃」ボタン（最後の敵）

### 表示タイミング

1. プレイヤーターン開始時: 非表示
2. アイテム選択時: 表示（`OnItemSelected()`が呼ばれた時）
3. 攻撃ボタンクリック時: 非表示（`OnAttackButtonClicked()`が呼ばれた時）

### ボタンのテキスト設定

- ボタンのテキストは実行時に動的に設定されます
- `AttackButton`プレハブの子オブジェクトに`TextMeshProUGUI`コンポーネントが必要です
- テキストは`GetComponentInChildren<TextMeshProUGUI>()`で取得されます

## 注意事項

- **AttackButtonContainer**には`HorizontalLayoutGroup`コンポーネントが必須です
- **AttackButton**プレハブには`Button`コンポーネントと`TextMeshProUGUI`（子オブジェクト）が必要です
- ボタンは動的に生成・削除されるため、Hierarchyに直接配置する必要はありません
- 初期状態では`AttackButtonPanel`は非表示にしておきます（`Initialize()`で自動的に非表示になります）

## レイアウトの調整

### ボタンのサイズを変更する場合

1. `AttackButton`プレハブを選択
2. **RectTransform**の**Width**と**Height**を変更
3. `AttackButtonContainer`の**HorizontalLayoutGroup**の**Child Control Size**で制御されます

### ボタン間の間隔を変更する場合

1. `AttackButtonContainer`を選択
2. **HorizontalLayoutGroup**の**Spacing**を変更（デフォルト: `20`）

### ボタンの配置位置を変更する場合

1. `AttackButtonPanel`を選択
2. **RectTransform**の**Position**を変更（デフォルト: `(0, -200, 0)`）
