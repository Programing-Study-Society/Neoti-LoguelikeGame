# バトルシステム：アイテム挙動詳細説明

## バトル開始時の初期化処理

### 1. `StartBattle()` が呼ばれる（外部から）
- `shouldStartBattle = true` に設定
- GameObjectを一度非アクティブ→アクティブにして `OnEnable()` を呼ぶ

### 2. `OnEnable()` が実行される
- `shouldStartBattle` が `false` の場合は何もしない（起動時の自動開始を防ぐ）
- `shouldStartBattle = false` にリセット
- `StartBattleInternal()` を呼ぶ

### 3. `StartBattleInternal()` の処理
1. **プレイヤー参照取得**
   - Inspectorで設定されていれば使用
   - なければ `GetComponent<player>()` または `FindObjectOfType<player>()` で検索

2. **既存の敵をクリア**
   - `ClearEnemies()` で前回のバトルの敵を削除

3. **アイテムDB初期化**
   - `InitItemDatabase()` で9種類のアイテムデータを登録

4. **敵生成**
   - `EnemySpawnManager.GenerateEnemyIds()` で敵IDリストを取得
   - `SpawnEnemies()` で敵を生成
   - 各敵に `EnemyStatus` を追加（DOT・デバフ管理用）

5. **アイテム管理初期化**
   - `InitializeBattleItems()` で `battleItemCounts` を初期化
   - `itemMaster.item_list` からレアリティごとの所持数をコピー

6. **プレイヤーHP初期化**
   - `battlePlayerHP = player.MAXHP` で全回復

7. **ターン設定**
   - `currentTurn = BattleTurn.Player` でプレイヤーターンに設定

8. **UI通知**
   - `NotifyBattleStartToUI()` でバトル開始をUIに通知
   - `NotifyPlayerTurnStart()` でプレイヤーターン開始を通知

---

## アイテム使用時の処理フロー

### 共通フロー
1. **UIから `OnItemUsed(itemId, rarity, enemyIndex)` が呼ばれる**
   - `itemId`: アイテムID (0-8)
   - `rarity`: レアリティ (0=Common=Small, 1=Rare=Middle, 2=Epic=Large)
   - `enemyIndex`: 敵インデックス（-1の場合は自分に使用）

2. **`OnItemUsed()` のチェック**
   - プレイヤーターンか確認
   - アクション処理中でないか確認
   - レアリティ→ItemLevel変換（0→Small, 1→Middle, 2→Large）

3. **`PlayerUseItem(itemId, level, enemyIndex)` が呼ばれる**
   - プレイヤーターンか確認
   - アクション処理中でないか確認
   - アイテム所持数をチェック（レアリティごと）
   - 所持数が0以下なら終了
   - アイテムDBに存在するか確認
   - **所持数を1減らす**（`battleItemCounts[itemId][rarityIndex]--`）
   - `CreateAdjustedItem()` でレアリティに応じた効果を計算
   - `PlayerActionRoutine()` コルーチンを開始

4. **`PlayerActionRoutine()` の処理**
   - `isActionProcessing = true` に設定（重複使用防止）
   - `ApplyItem()` でアイテム効果を適用
   - 0.3秒待機
   - バトル終了していなければ敵ターンに移行
   - `EnemyTurnRoutine()` を実行
   - バトル終了していなければプレイヤーターンに戻る
   - `isActionProcessing = false` に設定
   - `NotifyPlayerTurnStart()` でUIに通知

## 各アイテムの詳細挙動

### アイテム0: リペアユニット（回復）

**基本データ:**
- `effectType`: `Heal`
- `target`: `Self`（自分）
- `power`: 30（ベース値、実際は固定値を使用）

**レアリティ別回復量:**
- **Small (Common)**: 5,000 HP
- **Middle (Rare)**: 8,000 HP
- **Large (Epic)**: 15,000 HP

**処理フロー:**
1. `CreateAdjustedItem()` でレアリティに応じた回復量を設定
2. `ApplyItem()` → `ApplyItemToPlayer()` が呼ばれる
3. `battlePlayerHP = Mathf.Min(battlePlayerHP + item.power, player.MAXHP)` で回復
   - MAXHPを超えないように制限
4. `NotifyPlayerHPUpdate()` でUIにHP更新を通知

**使用例:**
- プレイヤーHP: 3,000 / 10,000
- Small使用 → 8,000 / 10,000 に回復
- Large使用 → 10,000 / 10,000（MAXHP上限）

### アイテム1: ガトリングガン（マルチヒット）

**基本データ:**
- `effectType`: `MultiHit`
- `target`: `OpponentSingle`（単体の敵）
- `power`: 5（ベース値、実際はATKベースで計算）
- `hitCount`: 5（ベース値、実際はランダム）

**レアリティ別設定:**
- **Small (Common)**: 
  - 攻撃力倍率: 1.0倍（ATK100%）
  - ヒット数: 1-6回（ランダム）
- **Middle (Rare)**:
  - 攻撃力倍率: 1.5倍（ATK150%）
  - ヒット数: 1-6回（ランダム）
- **Large (Epic)**:
  - 攻撃力倍率: 3.0倍（ATK300%）
  - ヒット数: 1-6回（ランダム）

**処理フロー:**
1. `CreateAdjustedItem()` で以下を計算:
   - `GetPlayerATK()` でプレイヤーATKを取得（ATKバフ考慮済み）
   - ヒット数を `Random.Range(1, 7)` で決定（1-6回）
   - 攻撃力 = `ATK × レアリティ倍率`
2. `ApplyItem()` → `ApplyItemToEnemy()` が呼ばれる
3. `item.hitCount` 回だけ `DealDamage()` を実行
   - 各ヒットで同じダメージ量を適用
4. `DealDamage()` で以下を計算:
   - 敵のDEFを取得
   - DEFデバフがあれば適用（DEF × (1 - debuffDEFPercent/100)）
   - ダメージ = `power - def`（最低1ダメージ）
   - 敵HPを減らす
   - UIに敵HP更新を通知
   - HPが0以下なら敵を削除

**使用例:**
- プレイヤーATK: 1,000
- 敵DEF: 200
- Small使用（倍率1.0、ヒット数4回）:
  - 1ヒット目: 1,000 - 200 = 800ダメージ
  - 2-4ヒット目: 各800ダメージ
  - 合計: 3,200ダメージ

### アイテム2: 重装ランチャー（強攻撃）

**基本データ:**
- `effectType`: `Damage`
- `target`: `OpponentSingle`（単体の敵）
- `power`: 25（ベース値、実際はATKベースで計算）

**レアリティ別設定:**
- **Small (Common)**: 
  - 攻撃力倍率: 4.0倍（ATK400%）
  - 失敗率: 1/20（5%）
  - 失敗時: ダメージ50%
  - 上振れ率: 1/30（約3.3%）
  - 上振れ時: ダメージ300%（元の3倍）
- **Middle (Rare)**:
  - 攻撃力倍率: 6.0倍（ATK600%）
  - 失敗率・上振れ率: 同上
- **Large (Epic)**:
  - 攻撃力倍率: 12.0倍（ATK1200%）
  - 失敗率・上振れ率: 同上

**処理フロー:**
1. `CreateAdjustedItem()` で以下を計算:
   - `GetPlayerATK()` でプレイヤーATKを取得
   - 基本攻撃力 = `ATK × レアリティ倍率`
   - **失敗判定**: 1/20の確率で失敗 → ダメージ50%
   - **上振れ判定**: 失敗でなければ1/30の確率で上振れ → ダメージ300%
   - 最終攻撃力 = 基本攻撃力 × 失敗/上振れ倍率
2. `ApplyItem()` → `ApplyItemToEnemy()` が呼ばれる
3. `DealDamage()` でダメージ計算・適用

**使用例:**
- プレイヤーATK: 1,000
- 敵DEF: 200
- Middle使用（倍率6.0）:
  - 基本攻撃力: 1,000 × 6.0 = 6,000
  - 通常時: 6,000 - 200 = 5,800ダメージ
  - 失敗時（5%確率）: 3,000 - 200 = 2,800ダメージ
  - 上振れ時（約3.3%確率）: 18,000 - 200 = 17,800ダメージ

### アイテム3: 火炎放射器（持続ダメージ/DOT）

**基本データ:**
- `effectType`: `DamageOverTime`
- `target`: `OpponentSingle`（単体の敵）
- `power`: 5（ベース値、実際はATKベースで計算）
- `duration`: 3（継続ターン数）

**レアリティ別設定:**
- **Small (Common)**: 
  - 1ターンあたり: ATK × 2.5倍
  - 継続ターン: 3ターン
- **Middle (Rare)**:
  - 1ターンあたり: ATK × 3.75倍
  - 継続ターン: 3ターン
- **Large (Epic)**:
  - 1ターンあたり: ATK × 7.5倍
  - 継続ターン: 3ターン

**処理フロー:**
1. `CreateAdjustedItem()` で以下を計算:
   - `GetPlayerATK()` でプレイヤーATKを取得
   - DOTダメージ = `ATK × レアリティ倍率`
   - 継続ターン = 3ターン
2. `ApplyItem()` → `ApplyItemToEnemy()` が呼ばれる
3. 敵の `EnemyStatus` に以下を設定:
   - `st.dotDamage = item.power`（1ターンあたりのダメージ）
   - `st.dotTurn = item.duration`（残りターン数）
4. **敵ターン開始時**（`EnemyTurnRoutine()`）:
   - 各敵の `st.dotTurn > 0` をチェック
   - `enemy.HP -= st.dotDamage` でDOTダメージを適用
   - `st.dotTurn--` で残りターンを減らす
   - UIに敵HP更新を通知
   - HPが0以下なら敵を削除
   - 3ターン経過すると自動的に解除

**使用例:**
- プレイヤーATK: 1,000
- 敵HP: 10,000
- Middle使用（倍率3.75）:
  - DOTダメージ: 1,000 × 3.75 = 3,750/ターン
  - 1ターン目: 10,000 - 3,750 = 6,250
  - 2ターン目: 6,250 - 3,750 = 2,500
  - 3ターン目: 2,500 - 3,750 = -1,250（撃破）

### アイテム4: サイバーハックモジュール（敵ATKデバフ）

**基本データ:**
- `effectType`: `DebuffATK`
- `target`: `OpponentSingle`（単体の敵）
- `power`: 5（ベース値、実際は%で設定）
- `duration`: 3（継続ターン数）

**レアリティ別設定:**
- **Small (Common)**: 
  - ATK減少: 10%
  - 継続ターン: 3ターン
- **Middle (Rare)**:
  - ATK減少: 30%
  - 継続ターン: 3ターン
- **Large (Epic)**:
  - ATK減少: 60%
  - 継続ターン: 3ターン

**処理フロー:**
1. `CreateAdjustedItem()` で以下を計算:
   - レアリティに応じた減少%を設定（10/30/60%）
   - 継続ターン = 3ターン
2. `ApplyItem()` → `ApplyItemToEnemy()` が呼ばれる
3. 敵の `EnemyStatus` に以下を設定:
   - `st.debuffATKPercent = item.power`（減少%）
   - `st.debuffATKTurn = item.duration`（残りターン数）
4. **敵ターン開始時**（`EnemyTurnRoutine()`）:
   - 敵の攻撃力計算時にデバフを適用:
     - `atk = enemy.ATK × (1 - debuffATKPercent / 100)`
   - プレイヤーへのダメージ計算:
     - `damage = atk - def`（最低1ダメージ）
   - ターン終了時に `st.debuffATKTurn--`
   - 3ターン経過すると自動的に解除（`debuffATKPercent = 0`）

**使用例:**
- 敵ATK: 1,000
- プレイヤーDEF: 200
- Middle使用（30%減少）:
  - 敵の実効ATK: 1,000 × (1 - 0.30) = 700
  - プレイヤーへのダメージ: 700 - 200 = 500（通常は800ダメージ）

## 敵ターン処理の詳細

### `EnemyTurnRoutine()` の処理順序

1. **プレイヤーバフのターン減少**
   - `playerBuffTurn--`（DEFバフ）
   - `playerBuffATKTurn--`（ATKバフ）
   - 0になったら解除

2. **UIに敵ターン開始を通知**
   - `NotifyEnemyTurnStart()`

3. **各敵の処理**（後ろから順に）:
   - **DOT処理**:
     - `st.dotTurn > 0` ならDOTダメージを適用
     - `st.dotTurn--`
     - HPが0以下なら敵を削除して次の敵へ
   
   - **敵の攻撃力計算**:
     - 基本ATKを取得
     - ATKデバフがあれば適用
     - `atk = enemy.ATK × (1 - debuffATKPercent / 100)`
   
   - **プレイヤーの防御力計算**:
     - 基本DEFを取得
     - DEFバフがあれば適用
     - `def = player.DEF × (1 + playerBuffDEF / 100)`
   
   - **ダメージ計算・適用**:
     - `damage = atk - def`（最低1ダメージ）
     - `battlePlayerHP -= damage`
     - UIにプレイヤーHP更新を通知
     - HPが0以下なら `EndBattle(false)` を呼ぶ
   
   - **敵デバフのターン減少**:
     - `st.debuffATKTurn--`
     - `st.debuffDEFTurn--`
     - 0になったら解除

4. **0.2秒待機**（次の敵の処理前に）

---

## バトル終了処理

### `EndBattle(bool win)` の処理

1. `currentTurn = BattleTurn.End` に設定
2. `ReflectBattleItems()` でアイテム所持数を反映:
   - `battleItemCounts` の内容を `itemMaster.item_list` に反映
   - レアリティごとの所持数を更新
3. 勝利/敗北のログを出力

---

## 重要な注意点

1. **アイテム所持数の管理**
   - バトル中は `battleItemCounts` で管理
   - バトル終了時に `itemMaster.item_list` に反映
   - レアリティごとに管理されている

2. **バフ・デバフのスタック**
   - 同じバフ/デバフを複数回使用すると、**上書き**される（スタックしない）
   - 最後に使用したアイテムの効果が適用される

3. **ターン管理**
   - アイテム使用後、0.3秒待機してから敵ターンに移行
   - 敵ターンはコルーチンで処理される（0.2秒間隔）

4. **ATKバフの影響範囲**
   - アイテム5（オーバークロック）を使用すると、以降のアイテム使用時のATKが増加
   - マルチヒット・強攻撃・DOTの計算に影響

5. **DEFデバフの影響範囲**
   - アイテム6（スタンガン）を使用すると、以降のダメージ計算時に敵DEFが減少
   - マルチヒット・強攻撃・AoEの計算に影響
