# お金・スキルポイント用プレハブ作成手順

## CreditSlot.prefab の作成

### 方法1: ItemSlot.prefabをコピーして作成（推奨）

1. Unityエディタで `Assets/Prefabs/UI/ItemSlot.prefab` を選択
2. 右クリック → **Duplicate**（複製）
3. 複製されたファイルの名前を `CreditSlot` に変更
4. 必要に応じて、CreditSlotプレハブの構造を調整

### 方法2: 新規作成

1. Unityエディタで `Assets/Prefabs/UI/` フォルダを選択
2. 右クリック → **Create → UI → Image** → 名前を `CreditSlot` に変更
3. CreditSlotを選択した状態で、右クリック → **UI → Image** → 名前を `CreditImage` に変更
4. CreditSlotを選択した状態で、右クリック → **UI → Text - TextMeshPro** → 名前を `CreditNameText` に変更

### CreditSlotプレハブの構造

```
CreditSlot (親、RectTransform)
├── CreditImage (子、Imageコンポーネント)
└── CreditNameText (子、TextMeshProUGUI)
```

### 設定項目

#### CreditSlot（親）
- **RectTransform**
  - Width: `200`
  - Height: `200`
  - Anchors: Center

#### CreditImage（子）
- **RectTransform**
  - Anchors: Top-Center
  - Position: `(0, 25, 0)`
  - Size: `(200, 200)`
- **Image**
  - Color: 白
  - Preserve Aspect: チェック

#### CreditNameText（子）
- **RectTransform**
  - Anchors: Bottom-Center
  - Position: `(0, -50, 0)`
  - Size: `(200, 50)`
- **TextMeshProUGUI**
  - Font Size: 適切なサイズ（例: 24）
  - Alignment: Center
  - Color: 白

### 注意点

- CreditSlotプレハブの子オブジェクト名は `CreditImage` と `CreditNameText` にしてください
- または、既存の `ItemImage` と `ItemNameText` という名前でも動作します（コード側で対応済み）
