# ダメージ表示プレハブ作成手順

## 概要
攻撃時にダメージ数値を表示するためのプレハブを作成します。

## プレハブの構造

```
DamageText (GameObject)
└─ Text (TextMeshProUGUI Component)
```

## 作成手順

### 0. DamageTextContainerの作成（推奨）
1. HierarchyでBattleScreenオブジェクトを選択
2. 右クリック → `Create Empty`
3. 名前を `DamageTextContainer` に変更
4. **コンポーネントは追加不要**（空のGameObjectのまま）

### 1. DamageTextの作成
1. Hierarchyで`DamageTextContainer`を選択
2. 右クリック → `UI` → `Text - TextMeshPro`
3. 名前を `DamageText` に変更

### 2. TextMeshProUGUIの設定
1. `DamageText`を選択
2. Inspectorで以下を設定：

#### 基本設定
   - **Text**: `-0`（一時的な値、実行時に変更される）
   - **Font Size**: 48以上（見やすいサイズ）
   - **Alignment**: 中央揃え（Horizontal: Center, Vertical: Middle）
   - **Color**: 白（実行時に変更される）
   - **Font Style**: Bold（太字推奨）

#### Outline（アウトライン）設定
**設定場所**: Inspectorの**「Extra Settings」**セクション（下の方にあります）

1. Inspectorを下にスクロールして**「Extra Settings」**セクションを展開
2. **「Outline」**セクションを展開
3. 以下の設定を行う：
   - **Outline Width**: `0.2`（アウトラインの太さ）
   - **Outline Color**: 黒（`R: 0, G: 0, B: 0, A: 255`）

**注意**: Outline Widthが0の場合はアウトラインが表示されません。0.2以上に設定してください。

### 3. RectTransformの設定
- **Width**: 200
- **Height**: 60
- **Anchor**: Center（中央）
- **Pivot**: (0.5, 0.5)

### 4. プレハブ化
1. `DamageText`オブジェクトを`Prefabs/UI`フォルダにドラッグ&ドロップ
2. プレハブ名を `DamageText.prefab` に変更
3. **注意**: プレハブ化後、Hierarchyの`DamageText`オブジェクトは削除してもOKです（プレハブとして保存されているため）
   - `DamageTextContainer`は残しておいてください（実行時にダメージテキストがここに生成されます）

## BattleScreenのInspector設定

### 必須設定項目
1. **Damage Text Prefab**: 作成した`DamageText.prefab`を設定

### オプション設定項目
2. **Damage Text Parent**: ダメージテキストの親オブジェクト
   - **推奨**: BattleScreenオブジェクト直下に空のGameObjectを作成して設定
   - **設定しない場合**: BattleScreenオブジェクト自身を親として使用します
   - **設定する場合**: 
     1. HierarchyでBattleScreenオブジェクトを選択
     2. 右クリック → `Create Empty`で空のGameObjectを作成
     3. 名前を`DamageTextContainer`などに変更
     4. Inspectorの「Damage Text Parent」フィールドにドラッグ&ドロップ
   - **メリット**: BattleScreenが非アクティブになった時に、ダメージテキストも一緒に非表示になります

### オプション設定項目（デフォルト値で動作）
- **Damage Text Duration**: 1.5秒（ダメージ表示時間）
- **Damage Text Move Distance**: 100ピクセル（上に移動する距離）
- **Player Damage Color**: 赤（プレイヤー被ダメージの色）
- **Enemy Damage Color**: 黄（敵被ダメージの色）

## 動作確認

1. UnityでPlayモードに入る
2. `summary`オブジェクトのInspectorメニューから「バトルを開始」を選択
3. アイテムを使用して敵に攻撃 → 敵の位置に黄色のダメージ数値が表示される
4. 敵が攻撃 → プレイヤーの位置に赤いダメージ数値が表示される

## 注意事項

- ダメージテキストは自動的にフェードアウトしながら上に移動します
- 複数のダメージが同時に発生した場合、複数のテキストが表示されます
- ダメージテキストは表示時間経過後に自動的に削除されます
